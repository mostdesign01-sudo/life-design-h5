# 宣传片 brief：你的小星球 · 15 秒竖版

留空项都由制作方决定，每项附一句理由。

| 项 | 选择 | 理由 |
|---|---|---|
| mode | product（产品片） | 产品本身就是主角：分数一变，星球跟着变，这个瞬间比任何解说都有说服力。 |
| subject | `planet.html`：你的小星球 | 设计人生蓝图的 3D 第一站。 |
| viewer | 小红书上 20–35 岁、正在纠结工作和生活方向的人，多数静音刷 | 他们想被理解，不想被评判；画面要温暖，不能像体检报告。 |
| end state | 想点开测一测自己的星球 | 结尾只留一个动作：测测你的小星球。 |
| length | 15 秒，9:16，1080×1920 | 小红书竖版信息流。 |
| frame rate | 30 | 3D 场景加角色动画。 |
| brand | 从产品提取：Planet Serif（思源宋体子集）、奶油底 #fbf3e8、墨蓝 #2f3756、强调橙 #c95a26 | 和产品页、明信片保持同一套视觉。 |
| facts | `promo/facts.json` | 画面上每句话都能在产品文案或代码里找到出处。 |
| assets | 从产品实时逐帧渲染 | 不用截图拼贴，画面里的星球就是用户会看到的那颗。 |
| style | 温暖写意的自然 + 克制排版 | 与 `planet-design` skill 一致。 |
| sound | 音乐加音效，无人声 | 静音也看得懂；开声音时，音效对上画面里真实发生的事。 |
| autonomy | unattended | 用户要求直接出片。 |
| toolchain | 产品同一套 Three.js 代码 + 虚拟时钟逐帧渲染（Playwright）+ ffmpeg 编码 | 没有另做一套动画，每一帧都是帧号的函数。 |
| sign-off | 「测测你的小星球」+「约 3 分钟 · 6 个小站」，卡片下方单独一枚「链接在评论区」 | 结尾的行动号召，用产品里原有的文案；「链接在评论区」是发布方式的假设，换平台时改这一句。 |

## 结构（96 BPM，一拍 0.625 秒，每段 4 拍 = 2.5 秒）

1. 0–2.5 秒 钩子：一颗悬浮的小星球缓缓转动，「你的人生，是一颗小星球」。
2. 2.5–5 秒 俯冲降落到地面，「健康、工作、娱乐和爱，都长在上面」。
3. 5–7.5 秒 工坊：分数从 2 走到 9，黑烟变白烟，「工作堵着，烟囱就冒黑烟」。
4. 7.5–10 秒 双生灯：灯泡随节拍一颗颗亮到 10，「爱有几分，灯就亮几颗」。
5. 10–12.5 秒 晚霞长椅：天空从阴灰变成粉橙色的暮色，「多久没好好看一次晚霞了？」
6. 12.5–15 秒 明信片升起，「测测你的小星球」。

贯穿全片的元素：橙色圆点加宋体分数。它在第 3 到 5 段跟着分数走，最后落进明信片底部的分数行。
