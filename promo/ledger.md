# 宣传片改动账本

每一轮渲染后，都由一位没看过制作过程的评审只看画面挑问题；这里记下问题、改法，以及改前改后的数字。

## 第 1 轮（整片首渲）

实测：1080×1920，30 fps，450 帧，15.000 秒；响度 -13.9 LUFS，峰值 -1.5 dBFS，LRA 4.9 LU；13.93–14.70 秒画面冻结 0.77 秒（上限 0.5 秒）。

评审结论：再改一轮。

| 问题 | 改法 | 改前 → 改后 |
|---|---|---|
| 明信片上露出本机测试地址 | `makePostcard` 可传入链接文字，片中写「链接在评论区」 | 地址可见 → 不再出现 |
| 明信片两侧漏出背后星球 | 卡片升起时铺一层奶油色底 | 漏出 → 不透明底 |
| 高潮撞在转场上：白烟、10 盏灯、晚霞 | 数值动画提前到段落前 0.5–0.75 拍开始、按十六分音符走；镜头在段尾前 0.3 秒才移动 | 达到最终分数后的停留：工作 -0.08 秒、爱 -0.31 秒、娱乐 0.12 秒 → 0.79 秒、0.48 秒、0.79 秒（按 timing.json 计算） |
| 晚霞段长椅被卡片挡住，天空不变金色 | 晚霞段改用专门镜头：在长椅背后朝太阳仰拍；娱乐分数接近满分时，整片天空过渡到暮色（产品同步改） | 长椅被遮挡 → 在卡片下方完整可见；天空中段颜色 #8fbde6 → #ffb489 |
| 分数卡太大，大数字落进右侧按钮区 | 卡片缩到 268px 宽，移到左上、字幕下方；去掉与卡片重复的小眉标 | 卡片右缘 x=1016（2 倍坐标）→ x=600 |
| 开场 2 秒几乎不动 | 开场转速提高到原来的 3.2 倍，同时缓慢推近 | 开场旋转 0.07 → 0.22 弧度/秒；画面高度 29 → 25 |
| 结尾冻结、行动号召太短 | 卡片落定后继续缓慢前推（+4.5%）；行动号召提前一拍出现，并加上「链接在评论区」 | 行动号召停留 1.7 秒 → 1.9 秒；冻结 0.77 秒 → 无 |

## 第 2 轮

实测：1080×1920，30 fps，450 帧，15.000 秒；响度 -13.9 LUFS，峰值 -1.5 dBFS，LRA 4.4 LU；没有 0.5 秒以上的冻结。

渲染后自查发现晚霞没出来：长椅背后朝太阳拍，整片天被太阳光晕冲成奶油色。改成从太阳一侧拍长椅，偏 20°，镜头对着暮色最饱和的半边天。改后，娱乐分数从 2 到 9，天空从灰白经过浅蓝变成粉橙色，长椅在画面中部（y≈520–650，按 960 高计），不进底部评论区。

评审结论：再改一轮。

| 问题 | 改法 | 改前 → 改后 |
|---|---|---|
| 明信片上「缠绕藤里，6 成是可以动手的新芽」在 facts.json 里没有出处 | 补上出处（main.js:814，由示例答案「可设计 60%」算出） | 无出处 → 有出处，并标为示例 |
| 明信片的分数、编号和日期像一位真实用户的结果 | 卡片右上角加橙底白字「示例」标签 | 无标注 → 13px 标签（2 倍后 26px） |
| 分数卡上的「示例」太小、太淡 | 字号 11 → 13px，颜色 #6b6f86 → #4f5570，加描边 | 2 倍后约 22px → 26px |
| 晚霞镜头左下角有一团灯光 | 查出是画框外日记路牌的灯；晚霞镜头里隐藏路牌（灯串在画面右侧之外，不受影响） | 光斑可见 → 不出现 |
| 分数卡换标签比字幕早出现 | 段落交界处分数卡和字幕同步淡出、淡入 | 换标签时卡片照常显示 → 和字幕一起淡出再淡入 |

## 第 4 轮（定稿）

实测：1080×1920，30 fps，450 帧，15.000 秒；响度 -13.8 LUFS，峰值 -1.5 dBFS，LRA 4.8 LU；没有冻结。高潮停留按评审计帧：白烟约 1.4 秒，10 盏灯约 1.1 秒，晚霞约 1.3 秒。

又换了一位新评审。结论：再改一轮。唯一的必须改是封面问题，用单独的封面图解决，视频本身不再改动。

| 问题 | 改法 | 改前 → 改后 |
|---|---|---|
| 小红书信息流按 3:4 显示封面，居中裁切会切掉第一行标题 | 另出一张 3:4 封面：取第 0 帧 y 110–1550 这一段，标题和星球都完整 | 居中裁切时标题被切掉 → 单独封面 1080×1440，标题完整 |
| （可选）明信片标题淡入时叠在转动的星球上 | 不改：这是 0.3 秒的交叉淡化，卡片落定后标题才出现 | — |
| （可选）明信片里的编号和「缠绕藤」一行字太小 | 不改：这是产品真实的明信片，片中照原样展示，整张卡标了「示例」 | — |
| （可选）链接胶囊离评论区近、停留 1.4 秒 | 不改：下沿约 y 696（按 960 高计），仍在 700 以上；片长固定 15 秒 | — |
| （可选）白烟时字幕仍说「冒黑烟」 | 不改，理由同第 3 轮 | — |

## 海报（3:4）

用户反馈：旧封面当海报用，没有视觉中心，星球上没有主体，放大的草很乱。

改法：换成一张专门布景的静帧。旅人坐在星球顶上的长椅上，背对镜头看夕阳，太阳摆在长椅右侧。镜头拉远，露出星球弧线。长椅和旅人放大 1.8 倍，缩略图里也看得清。草、云、石子、灯串和路牌都隐去。

| 轮次 | 评审问题 | 改法 |
|---|---|---|
| 1 | 弧度太平，像山坡；行动号召压在草上；两行小字在缩略图里约 7px；左侧路灯斜着被裁掉 | 镜头拉远到画面高 12 个单位，主体放大 1.8 倍；去掉草和灯串；小字 12px → 15px |
| 2（结论：可以用） | 半透明石子像污点；椅腿有高光竖线，背包挂灯漏光；睡袋横出来，轮廓乱 | 隐去石子；椅腿改哑光；背包只留包身；旅人往前坐 0.05；小字再放大到 17px（2 倍后 34px）；行动号召加箭头 |

## 第 6 轮（开场换成海报画面）

用户同意让开场和海报统一。

| 改动 | 做法 |
|---|---|
| 0–2.5 秒换成海报画面 | 布景抽成 `promo/stage.js`，海报和宣传片共用。开场镜头从画面高 12.5 推到 11，太阳摆在长椅右侧。开场分数和结尾相同（7/9/9/10），所以天空是暮色 |
| 2.5 秒切换 | 在重拍上撤掉全部布景，镜头直接放到原来的整颗星球远景，再接产品自己的俯冲。俯冲画面和之前一致 |
| 竖版画面里树抢主体 | 布景时隐去长椅 1.2 弧度以内的树和灌木（世界每帧会重设可见性，所以放在渲染前执行） |
| 开场主体发虚 | 开场时相机处在 intro 模式，移轴焦点落在星球中心；布景时把焦点带对到长椅 |
| 开场露出路牌 | 渲染脚本每帧都会重设路牌可见性（这是给晚霞镜头用的），改成只在俯冲之后生效 |

又换一位新评审。结论：再改一轮。

| 问题 | 改法 | 改前 → 改后 |
|---|---|---|
| 0082→0083 旅人一帧从坐变站，背包瞬移到背上 | 不再让旅人站起来：切点之后旅人一直坐在长椅上，俯冲直接落到长椅上的他 | 有一帧跳变 → 没有跳变 |

| （可选）首帧按 3:4 居中裁切会切到标题 | 视频封面直接用海报 | — |

最后一轮新评审结论：可以发布。四条可选意见都不改：
- 切点处太阳和草地一帧之内变化：这是有意的硬切，长椅、旅人、背包位置和暖色天空都接上了。叠化会让布景和产品画面重叠出半透明的重影。
- 起始低分只在分数卡淡入时露一下：数值动画已经为高潮停留往前挪过，再停 0.4 秒会把高潮的停留压回 1 秒以下。
- 2.5–5 秒这一拍没扫到四样东西：这一拍讲的是「落地」，四样东西在后面三站依次出现。
- 明信片升起前约 0.5 秒是奶油色过渡：这是星球淡出到明信片的交叉淡化，卡片落定后画面是满的。
