# 设计人生蓝图

一个单文件静态 H5，用斯坦福人生设计课的对话节奏，帮助用户完成：

- 四个仪表盘：健康、工作、娱乐、爱
- 真问题雷达：区分重力问题和可设计问题
- 工作观与人生观指南针
- 心流与能量地图
- 三个五年奥德赛计划
- 可复制、可下载的设计人生蓝图

## 方法背景

这个项目受到 Bill Burnett 和 Dave Evans 合著的 *Designing Your Life: How to Build a Well-Lived, Joyful Life* 启发。它在中文语境里常被称作《斯坦福大学人生设计课》。

这本书把设计思维带入人生选择：人生不是一道需要算出唯一标准答案的工程题，而更像一个可以反复试做、快速反馈、持续迭代的设计项目。它强调先看见自己当下的位置，再重新定义问题，分清哪些是无法直接改变的“重力问题”，哪些是可以通过行动、访谈和原型来验证的真问题。

本 H5 主要借鉴并产品化了这些方法线索：

- 健康、工作、娱乐、爱的四个仪表盘
- 重力问题与可设计问题的区分
- 工作观与人生观的指南针
- 心流、回血和消耗的能量地图
- 三个平行的五年奥德赛计划
- 低成本人生设计采访和原型行动

## 两位作者

**Bill Burnett** 是斯坦福设计教育者、设计思维实践者，也是 Life Design 课程体系的重要推动者。他的工作长期连接产品设计、设计教育和人生设计。

**Dave Evans** 是斯坦福设计教育者、创业者和组织实践者。他和 Bill Burnett 一起把设计思维从产品与服务设计延展到个人选择、职业路径和生活原型。

这不是一个官方授权产品，也不替代心理咨询、职业咨询或医疗建议。它只是一个个人学习和实践项目，用更轻、更可操作的界面，把 Life Design 的对话节奏带到浏览器里。

## 3D 小星球（第一站）

[`planet.html`](planet.html) 把问卷的前两步做成了一颗可以走动的 3D 小星球，主角是一个背包旅人，每位访客会分到自己的星球编号（如 LD-2741）：

- 泉水 = 健康，工坊 = 工作，晚霞长椅 = 娱乐，双生灯 = 爱。拖动分数时，星球会实时变化：泉水变清或变浑、草地变绿或发黄；工坊烟囱冒白烟或黑烟、窗户发暖光或烧得发红；天空更暖或更灰；两盏灯之间的灯串亮起几颗、灯柱靠近还是分开
- 缠绕藤 = 核心困扰。写下困扰后，老藤的大小代表重力问题，旁边发光的新芽代表可设计的部分，并调用一次 AI 关键追问
- 星球日记：写下红灯项的原因，生成一张“我的小星球”明信片
- 远处的引力星、指南针星、心流星、锚点星、三岔路星是后续关卡（重力问题、工作观与人生观、心流与能量、锚点、奥德赛计划）的预告，目前跳转到完整问卷

星球和问卷共用同一份 `localStorage` 进度：在星球上答完的题，回到 `index.html` 会接着往下走。

操作：手机左侧拖动移动、右侧拖动转视角、双指缩放；电脑 WASD 移动、拖动鼠标转视角、滚轮缩放、Enter 查看。点任意物件，角色会自己走过去。

技术上是纯静态的 Three.js（`vendor/three.module.min.js` 及 `vendor/three-addons/` 里的后期处理模块，r160，MIT），无构建、不依赖 CDN。画面是“温暖写意的自然 + 克制的设计感”：金色斜阳、柔和投影、天空环境光、随风的草和树、积云，叠加泛光、移轴和调色；文字和界面用克制的排版。曾试过纪念碑谷式的平涂几何风格，最终没有采用。所有模型都是代码生成的。代码在 [`planet/`](planet/)：`world.js` 搭场景，`look.js` 负责后期与手绘贴图，`main.js` 管镜头、操作和对话，`state.js` 负责和问卷共用进度。

排版用两种字体：标题、名称和数字用思源宋体子集（`vendor/fonts/`，SIL OFL，约 100KB，只含页面用到的字），正文用系统黑体。改了页面上的中文文案后，用 `scripts/subset-font.py` 重新生成字体子集。完整的视觉、排版、动效和检查流程写在项目 skill [`.claude/skills/planet-design/SKILL.md`](.claude/skills/planet-design/SKILL.md) 里，做新星球时按它来。

页面会在开场几秒测帧率，较慢的手机自动降低分辨率、关掉泛光。也可以在地址后加 `?quality=0`、`1` 或 `2` 手动指定画质。

## 15 秒竖版宣传片

`promo/` 里是小星球宣传片的全部源文件。画面从产品本身逐帧渲染，不用截图拼贴。

- `brief.md`：片子的取舍和结构。`facts.json` 列出画面上每句话的出处，片中分数都标「示例」。`style.md` 是样式规范，`ledger.md` 记录每轮评审的问题和改法。
- 先写声音：`python3 promo/music.py <工作目录>` 生成音乐、音效和 `timing.json`，画面按这份时间表踩点。
- 渲染：先在仓库根目录起一个静态服务（如 `python3 -m http.server 8612`），再运行 `node promo/render.mjs http://127.0.0.1:8612 <工作目录>/timing.json <工作目录>/frames`。页面跑在虚拟时钟上，每一帧都只由帧号决定，可以只重渲某一段（末尾加上起止秒数）。
- 海报：`node promo/poster.mjs http://127.0.0.1:8612 <输出.jpg>` 输出 3:4 海报（1080×1440）：长椅上的旅人背对镜头看夕阳，排版在 `promo/poster.html`。布景（旅人坐下、道具放大、隐去杂物、摆太阳）写在 `promo/stage.js`，宣传片开场 2.5 秒也用它；产品本身不变。
- 编码和检查：`promo/encode.sh <工作目录>` 输出 `promo-9x16.mp4` 和纯音乐版 `music-only.m4a`（响度 -14 LUFS）；`promo/qa.sh <视频> <输出目录>` 输出规格、冻结检测、响度和联系表。
- 改了片中文字后，重新生成字体子集：`python3 scripts/subset-font.py <fontsource 包目录> . 600 promo/promo-serif-600.woff2 promo/overlay.js`。

## 记录与隐私

H5 会把填写进度保存在当前浏览器本机的 `localStorage` 中，用来支持刷新后继续填写。提交关键节点时，相关回答会发送到 AI 后端生成短追问；点击“AI 深度蓝图”时，当前回答会发送到 AI 后端生成完整分析。点击页面右上角的“重新开始”按钮可以清空本机记录。

## AI 关键追问与深度蓝图

项目已接入一套克制的 AI 中间版：

- 前端：关键节点自动生成“AI 关键追问”，报告页提供“AI 深度蓝图”
- 后端：[`server/`](server/) 中的 Node.js 最小 API 服务
- 提示词：[`prompts/life-design-system-prompt.md`](prompts/life-design-system-prompt.md)
- 方案文档：[`docs/AI_BACKEND_PLAN.md`](docs/AI_BACKEND_PLAN.md)

关键追问只在核心困扰、指南针、能量、奥德赛这几个节点调用 AI，每次返回一个短洞察、一个追问和一个低成本原型动作。用户完成问答后，还可以调用一次 AI 深度蓝图，生成更深入的真问题重定义、能量地图、奥德赛计划重写和 90 天原型计划。每次追问都会带上前面各站的回答，以及用户对之前追问的回应（追问下面可以选填回答），所以 AI 能把前后的线索串起来；深度蓝图也会收到这些追问和回应。用户文字里出现明显的绝望或自伤信号时，前后端都会改为温和回应并给出求助热线，不做人生设计分析。API Key 只放在后端服务器环境变量中，不要写进前端。

当前 AI 骨架还包含一个最小商业化机制：

- 每个浏览器每天免费 4 次 AI 关键追问
- 每个浏览器每天免费 1 次 AI 深度蓝图
- 关键追问超出后降级为固定反馈
- 深度蓝图超出后需要激活码
- 激活码由作者手动发放
- 后端记录调用次数、tokens、估算成本和成功/失败状态

## 本地使用

直接用浏览器打开 `index.html` 即可。

如果想用本地服务预览：

```bash
python3 -m http.server 8024
```

然后访问：

```text
http://127.0.0.1:8024/
```
